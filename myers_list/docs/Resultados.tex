\subsection{Uso de Memória}

    A Tabela \ref{tab:memoria} apresenta o uso de memória de cada variante para uma lista de 1.000.000 de elementos.
Como era esperado, a Basic e a Improved Myers List apresentam exatamente o mesmo uso de memória 
(38,15 MB), uma vez que ambas mantêm o mesmo número de apontadores por célula, sendo apenas diferentes na maneira como o apontador jump é atribuído durante o cons.
A Okasaki List  apresenta o menor uso de memória de todas as variantes (22,89 MB).

A Advanced Myers List (53,41 MB) apresenta um uso de memória superior ao das variantes Basic e Improved não por introduzir novos apontadores, 
a estrutura de célula mantém-se igual, reaproveitando o próprio apontador jump para servir de uncle/inc/greater consoante o tipo de nó lógico, mas por 
cada célula ter de guardar explicitamente a informação de RHD e RED necessária para a sua construção e para a otimização do lookup face as variantes anteriores. 

A Dense Advanced Myers List (75,02 MB) leva esta ideia mais longe, ao consolidar cada nó lógico numa única célula, os campos rhd, red e o  identificador do 
tipo de nó (o campo more, com os construtores Normal, Skip e Leaf) passam a estar presentes em todas as células, que consequentemente exige um consumo de memória ainda
superior ao da Advanced original.
